An open-source Obsidian plugin that opens [marimo](https://marimo.io) reactive Python notebooks inside your Obsidian vault.

- Registers the `.py` extension, so notebooks open like any other file in the vault
- Each notebook is backed by a local marimo server
- Supports both the full reactive editor and app mode
- Installs marimo automatically when it is missing

Distributed as a community plugin, with packaged releases and installation instructions.

Source code: [marimo4obs on GitHub](https://github.com/kammmran/marimo4obs)
