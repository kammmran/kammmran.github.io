GPU Memory Requirement Calculator
Estimate the GPU memory a deep-learning model needs for inference or training. Enter the parameter count and precision; the tool adds optimizer state, gradients and a rough activation budget, then suggests which GPUs fit. Back-of-the-envelope planning before you queue a job. Local.
Rough estimate: weights + (training only) gradients and optimizer state + an activation budget from batch × tokens × hidden × layers. Real usage depends on framework, attention implementation (e.g. FlashAttention), gradient checkpointing and fragmentation — add ~20% headroom.
