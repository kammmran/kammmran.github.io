Unit Test Skeleton Generator
Paste Python or JavaScript function definitions and get ready-to-fill test skeletons — pytest/unittest for Python, Jest for JS — one stub per function with argument placeholders and TODO assertions, plus edge-case reminders. Removes the boilerplate so you actually write the tests. Local.

  

  
These are skeletons, not generated assertions — the tool can't know what your functions should return, so it leaves TODOs and edge-case prompts (empty input, boundaries, types). Fill them in with expected values.
