Code Complexity Analyzer
Code Complexity & Quality Analyzer
Paste a function or file (Python, JS, R, Java…) and get readability metrics: lines of code, comment ratio, estimated cyclomatic complexity, maximum nesting depth, longest line, and a quality score with suggestions. A quick static check for research code. Local - your code is never uploaded.
Cyclomatic complexity is estimated by counting decision points (if/for/while/case/&&/||/?...). It's a heuristic over text, not a full parse, so treat numbers as indicative. Lower complexity and nesting → easier to test and maintain.
