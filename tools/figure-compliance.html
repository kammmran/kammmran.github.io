Figure Compliance Checker
Journal Figure Compliance Checker
Check a figure against a journal's submission rules before you upload. Pick a publisher preset (or set your own), drop the image, and get a pass/fail report on column-width fit, effective DPI, file format, and file size. Everything is computed locally.
Presets approximate common publisher guidance and may change - always confirm against the journal's current author instructions. Vector formats (SVG/PDF/EPS) are resolution-independent and pass DPI checks by default.
