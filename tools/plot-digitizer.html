Plot Digitizer
Plot Digitizer
Recover the underlying data from a chart image. Calibrate the two axes by clicking known reference points, then click each data point to read off real coordinates - supports linear and log scales. Export the recovered series as CSV. Works on scatter, line and bar plots; runs entirely in your browser.
Mode:
How to use: set each reference's value in the boxes, pick the matching mode, and click that spot on the axis (e.g. where X = 0 and where X = 10). Do the same for Y. Then switch to Data points and click each marker. Zoom your browser for precision on dense plots.
