Dependency Analyzer
Dependency & Reproducibility Analyzer
Paste a requirements.txt, environment.yml, package.json, or a block of import statements. The tool lists the dependencies, flags which are not version-pinned (a common reproducibility hazard), and rates how reproducible the environment is. Local.
For a reproducible research environment, pin every dependency to an exact version (==) and record the language/runtime version too. Imports of standard-library modules are listed but not counted as external dependencies.
