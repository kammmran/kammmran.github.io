Journal Figure Template Generator
Generate a sized, guide-marked template to build a multi-panel figure on. Set the journal column width and target DPI, choose a panel grid, and download a PNG (or transparent SVG overlay) at exact pixel dimensions with panel boxes and labels — drop it into your design tool as a layout guide so your figure fits first time.
The PNG is exactly the pixel size your figure should be (width mm ÷ 25.4 × DPI). Build your panels inside the marked boxes, then delete the guide layer before export. Use the SVG overlay if your tool supports placing a vector guide on top.
