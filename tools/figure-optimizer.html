Publication Figure Optimizer
Get a figure submission-ready: resize to an exact print width at a target DPI, convert between PNG/JPEG/WebP, drop to grayscale, set a white matte for transparent images, and trim file size. See the before/after size and export. Pixels never leave your browser.
Result preview
Use PNG/TIFF-style lossless for line art and plots; JPEG/WebP for photographs. Note browsers can't write a DPI tag into PNG — the pixel dimensions are what matter, and the tool reports the print size they yield. Never upscale to "add" resolution; it won't add real detail.
